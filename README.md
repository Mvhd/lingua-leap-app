# LinguaLeap 🚀

**Social Interaction Language App Powered by Gemini AI**

LinguaLeap is a revolutionary language learning ecosystem that transforms solo study into an addictive team sport. Master 29+ languages through real-time voice battles, dynamic AI-generated classrooms, and community-driven progress.

---

## 🌟 Key Features

### 🧠 Hyper-Personalized AI Lessons
Our "Learning Track" doesn't follow a static book. The Gemini AI generates fresh, dynamic lessons based on your specific level and progress every 10 days.

### 🎙️ Real-Time Voice Validation
Don’t just tap buttons. **Speak!** Our integrated AI evaluates your pronunciation and phonetics instantly, providing real-time feedback to build your real-world confidence.

### 🎮 Competitive Voice Games
Challenge friends or find global opponents in our **Voice Match** arena. 
- **Friendly Mode:** Play directly with up to 5 members of your group.
- **Global Matchmaking:** Use our "Find Match" system to battle learners at your exact level worldwide.

### 👥 The Social Classroom
Create or join language groups. Chat with members, compete for points, and watch your group's collective strength grow. Includes:
- **Live Presence:** See who's online and ready to learn.
- **Smart Mentions:** @mention group members in chat.
- **Instant Translation:** Tap any message to see it in your native language.

### 🌍 29+ Languages Supported
From Arabic and Hindi to Spanish and French. We provide **transliterations** for every non-Latin script to help beginners hit the ground running.

## 🛠️ Technical Stack

- **Frontend:** [Flutter](https://flutter.dev/) (Cross-platform iOS/Android)
- **Backend:** [Firebase](https://firebase.google.com/) (Auth, Firestore, Cloud Functions, Cloud Storage)
- **AI Engine:** [Google Gemini AI](https://deepmind.google/technologies/gemini/) (via Vertex AI / Cloud Functions)
- **Monetization:** [RevenueCat](https://www.revenuecat.com/)
- **State Management:** [Provider](https://pub.dev/packages/provider)
- **UI Components:** [Shadcn UI (Flutter)](https://shadcn-ui.com/)

## 🚀 Getting Started

### Prerequisites
- Flutter SDK `^3.8.1`
- Android Studio / Xcode
- A Firebase Project

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/your-repo/lingua_leap.git
   cd lingua_leap
   ```

2. **Install dependencies:**
   ```bash
   flutter pub get
   ```

3. **Configure Environment Variables:**
   Create a `.env` file in the root directory or pass defines at build time:
   ```bash
   REVENUE_CAT_APPLE_KEY=your_key
   REVENUE_CAT_GOOGLE_KEY=your_key
   ```

4. **Run the app:**
   ```bash
   flutter run --dart-define=REVENUE_CAT_APPLE_KEY=xxx --dart-define=REVENUE_CAT_GOOGLE_KEY=xxx
   ```
